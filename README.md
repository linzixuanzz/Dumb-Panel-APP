# 呆呆面板 APP

呆呆面板 Flutter 客户端，用于在移动端管理面板、任务、脚本、环境变量、订阅、依赖、通知、安全设置与备份恢复。

## 当前版本

- APP：`v2.0.0`
- 适配面板：`v4.0.0`（老面板可用，v4.0 专属的统计卡片会自动隐藏）

## 本次适配重点

- 全新外观：iOS 26 式干净留白、悬浮玻璃底栏，浅色 / 深色 / 跟随系统；底栏改为 任务 / 日志 / 概览 / 变量 / 设置。
- 常用任务卡片与按住运行、任务详情弹层（月历、P90）、日志四色筛选与错误行、概览页、变量遮蔽与更新时间（#27）、11 种快捷排序（#28）。
- 安卓长按图标快捷方式、桌面小组件、可选的「任务运行中」常驻通知。

## 常见问题

- **登录被面板拒绝（403）**：多见于在群晖、飞牛等 NAS 中通过 Nginx Proxy Manager 或公网域名反代访问的场景。请优先把面板升级到 `v2.3.0` 及以上；升级前可临时在面板 `config.yaml` 的 `cors.origins` 中加入完整公网地址，例如 `https://域名:端口`。
