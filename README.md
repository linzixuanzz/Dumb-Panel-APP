# 呆呆面板 APP

呆呆面板 Flutter 客户端，用于在移动端管理面板、任务、脚本、环境变量、订阅、依赖、通知、安全设置与备份恢复。

## 当前版本

- APP：`v1.4.5`
- 适配面板：`v3.4.2`

## 本次适配重点

- 脚本编辑器改为按行渲染，几千行的长脚本打开、滚动、打字都不再卡顿（#25）；脚本页与配置文件页都已换用。

## 常见问题

- **登录被面板拒绝（403）**：多见于在群晖、飞牛等 NAS 中通过 Nginx Proxy Manager 或公网域名反代访问的场景。请优先把面板升级到 `v2.3.0` 及以上；升级前可临时在面板 `config.yaml` 的 `cors.origins` 中加入完整公网地址，例如 `https://域名:端口`。
