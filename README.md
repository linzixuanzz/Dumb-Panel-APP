# 呆呆面板 APP

呆呆面板 Flutter 客户端，用于在移动端管理面板、任务、脚本、环境变量、订阅、依赖、通知、安全设置与备份恢复。

## 当前版本

- APP：`v1.4.3`
- 适配面板：`v3.3.9`

## 本次适配重点

- 「更多」新增「配置文件」，可直接编辑 config.sh（仅管理员，#22）。
- 任务卡左滑新增「日志」，一步打开最新日志。
- 窄屏手机上环境变量页的「+」、订阅卡片的删除按钮不再被挤出屏幕（#21、#23）。
- 依赖管理上方的统计和筛选随列表滚走，看 Python 依赖不再挤（#23）。
- 镜像源新增「PyPI 官方」「npm 官方」；在面板 v3.3.9 及以上保存才会生效。

## 常见问题

- **登录被面板拒绝（403）**：多见于在群晖、飞牛等 NAS 中通过 Nginx Proxy Manager 或公网域名反代访问的场景。请优先把面板升级到 `v2.3.0` 及以上；升级前可临时在面板 `config.yaml` 的 `cors.origins` 中加入完整公网地址，例如 `https://域名:端口`。
