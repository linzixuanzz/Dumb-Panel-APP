# v1.3.0

## 更新内容

这一版做了三件事：界面全面扁平化、把面板的配置能力搬到手机上、修掉三个正在悄悄损坏数据的缺陷。

### 修复

- **邮件通知渠道被写坏后无法发送**：APP 编辑邮件渠道时会把 SSL 开关写成布尔值，而面板要求配置项全是字符串。结果是**该渠道的所有通知连同「测试」按钮一起失效**，而界面上没有任何提示。已修正，并把 SSL 从开关改成「自动 / 启用 / 关闭」三态下拉——面板本来就是三态，用开关表达会把「自动」压成「关闭」。

  > 受影响的渠道请配合面板 `v3.0.1`：打开编辑再保存一次即可自愈。

- **备份漏掉「任务视图」**：从 APP 发起的备份不包含分组视图与自定义筛选排序，恢复时自然也没有。

- **「上次结果」把已终止说成失败**：手动停止的任务，APP 显示「失败」。面板对这两种情况是分开的。

- **未知状态被显示成某个已知状态**：面板新增依赖状态时 APP 会说「已安装」、新增任务类型时会说「常规定时」——**这比显示空白更危险**，用户会照着错误的信息去排查。现在一律显示原始值。共修正 8 处。

- **订阅列表超过 20 条看不见**：分页参数超过面板上限 100 时会被静默回落到 20，第 21 条起就没了。

- **日志「已终止」显示成「运行中」**：终止的日志和真在跑的日志颜色一样，肉眼分不出。

### 新增

- **系统设置从 10 项变 47 项**：整组定时备份、验证码配置、资源告警阈值、会话上限、时区、面板标题等此前在手机上根本改不了。现在设置页由面板下发的定义驱动，**面板以后新增配置项，APP 不用更新就能看到**。

  > 其中三项设为只读（守护方式、systemd 服务名、上次检查更新时间）：它们是安装事实或机器状态，不是偏好。服务名改错会导致面板起不来，而正因为起不来就没法再从 APP 改回去。

- **通知渠道字段补齐**：面板支持 55 个配置项，APP 原来只有 24 个有输入框，`custom` 渠道更是完全没有表单。现在字段定义由面板下发，**新增渠道或字段 APP 会自动跟上**。

- **订阅支持私有仓库**：补上鉴权方式、用户名、Access Token 与 SSH 密钥选择器，此前私有仓库订阅在 APP 上建不了。

- **定时规则模板**：从 3 条硬编码扩展到面板提供的 21 条，按场景分组；填写 cron 时会实时显示下次执行时间（按**面板时区**计算，不是手机时区）。

- **仪表盘补上「今日终止」**：此前「今日成功 + 今日失败」对不上今日执行总数。

- **日志详情页支持「下载原始日志」**：与面板 Web 端一致，由服务端把磁盘上的日志文件原样传下来，逐字节保留裸 `\r` 与终端控制序列。日志很大时不必等页面把几 MB 文本铺成富文本才能拿到内容。下载后弹系统保存框自己选位置，**不需要任何存储权限**。内容仅存于数据库的短日志没有独立文件，点了会直接说明原因。

- **环境变量导入导出**：与面板 Web 走同一对接口，两边可以互导。导出带备注、分组与启用状态；同名多条（多账号）一行一条，不会被压平。导入分「合并」与「替换」，前者遇到文件里同名同备注重复时会**拦下来**——面板那条接口没有这道守卫，直接导会静默把多条写成一条。

### 优化

- **界面全面扁平化**：去掉全部投影与渐变，圆角从 11 种取值收敛成 5 档，46 处卡片统一到同一个组件。仪表盘的装饰圆一并删除——它因为裁剪方式的问题，实际渲染成一个带两条直边的色块，从来就不是设计想要的样子。

- **列表更密**：任务页每屏从 1 张卡变 2 张（此前有一个总是渲染的分组头挡在前面，即使你一个分组都没建过）；日志、环境变量、脚本、订阅每屏各多一行。

- **耗时改用时分秒**：`4711.9s` 现在显示 `1h18m`。分档 `856ms` / `12.3s` / `5m12s` / `1h18m`。

- **失败提示变红**：此前 36 处失败与「保存成功」长得一模一样，只能靠读文案分辨。

- **请求失败能看见原因**：任务、日志、环境变量三个列表在断网时会显示错误和重试按钮，而不是「暂无数据」。

- **登录过期会自动续期**：此前这段逻辑因为 4xx 被当成成功响应而**从未执行过**，表现是页面莫名其妙空白，只能手动退出重登。

- **实时日志重连时也会自动续期**：任务实时日志、日志详情流、依赖安装日志、订阅拉取流走的是另一条链路，此前重连撞上登录过期只会弹「认证失败」。同时修掉两处**假的成功**——依赖安装和订阅拉取断线时，显示的是绿色的「安装完成」「拉取完成」。

- **实时日志重连不再翻倍**：面板在重连时会把历史从头重放，日志详情页此前完全没有去重，重连一次内容就多一份。

### 说明

- 本版与面板 `v3.0.1` 配套，但**两边互不依赖**：APP 在旧面板上会自动降级（少几项配置、渠道字段用内置快照），面板升级后不装新 APP 也能正常用。
- 系统设置与通知渠道现在读面板下发的定义。连接旧面板时字段可能比上面写的少，这是预期行为。
- 测试从 1 个空壳用例增加到 182 个。
