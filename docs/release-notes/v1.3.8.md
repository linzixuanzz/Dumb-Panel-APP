# v1.3.8

## 新功能

- 任务页可以批量设置通知：多选后点「通知设置」，一次开启 / 关闭失败、成功通知。需要面板 v3.3.3 及以上。
- 日志详情「⋮」菜单新增「打开已结束的日志时定位到底部」，与面板网页端共用同一个账户设置（需要面板 v3.3.3 及以上）。没设过时 App 仍默认在底部。

## 优化

- 镜像源设置与面板对齐：默认源标在腾讯云上，补上豆瓣、华为云、天翼云、中科大，每类都有「恢复默认」。
- 拖拽排序松手即保存；有运行中的任务、或当前视图带排序规则时会提示原因，不再白拖。

## 修复

- 在 App 里拖拽排序会悄悄改掉开机任务的执行顺序。现在只改列表顺序，与网页端一致（需要面板 v3.2.1 及以上）。
- 只改一种镜像源时，没改的也被一起提交，部分系统上会报错。

## 注意

- 与面板 v3.3.3 同期发布；装在老面板上也能用，批量设置通知会提示升级面板。
