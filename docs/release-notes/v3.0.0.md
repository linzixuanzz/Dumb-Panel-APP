# v3.0.0

## 全新外观

- 改为「松弛留白」风格：浅色是暖纸底配白卡片，深色改为柔和的深灰；主按钮、开关、选中态统一用钴蓝色。
- 字号与字重整体收小，卡片带浅描边和轻投影；底栏换成线性图标。
- 概览、设置、任务列表、订阅、依赖按新风格重排。

## 日志阅读页

- 任务运行日志、日志详情、面板日志、脚本调试、依赖安装日志、订阅拉取日志统一成全屏阅读页：顶部是状态胶囊，底部是操作栏。
- 新增页内搜索（高亮，可在命中之间上下跳转）、「首处报错」一键定位、显示行号、自动换行，以及可选的护眼暗底终端。
- 上翻查看时，右下角显示「恢复跟随 · 新增 N 行」，点一下回到最新。
- 运行结束后会查询这次运行的真实结果，显示成功 / 失败 / 已终止。
- 任务日志页可以直接停止运行、重新运行、跳到对应脚本（需要操作员权限）；依赖安装日志页可以取消安装、重新安装，连接断开时可以重新连接，并显示断开原因。
- 脚本「调试运行」改为全屏页，实时显示耗时，可以停止或重新运行。
- 面板日志的筛选收进右上角：级别、关键字（由面板在整份日志里筛选）、行数（300 / 1000 / 3000 快捷档，或自己填，最多 10000）。

## 新功能

- 变量：编辑已禁用的变量，改了值保存后自动启用，不用再去「已禁用」区找它（#29）。只改名称、备注、分组时不动启用状态。

## 修复

- 依赖日志：安装成功、失败、已取消分别显示，不再一律显示「安装完成」；卸载时按卸载显示。
- 订阅拉取日志：按面板记录的结果显示「拉取完成」「拉取失败」「已停止」，失败的拉取不再显示成完成；连接断开时提示拉取可能仍在进行。
- iOS：长按输入框的菜单（粘贴、全选等）显示中文（#28）。

## 注意

- 面板没有设置日志底色时，APP 的默认日志底色改为暖纸色 / 深灰，和网页端不再相同；想两边一致，可以在面板设置里指定日志底色。打开「护眼暗底终端」会覆盖面板设置的日志底色，只对本机生效。
- 脚本调试和订阅拉取日志从底部弹层改为全屏页，用左上角返回或系统返回键退出。
- 日志页底部的「停止运行」「重新运行」「取消安装」「重新安装」点一下就执行，没有二次确认。
- 开关打开时的颜色从绿色改为蓝色。
