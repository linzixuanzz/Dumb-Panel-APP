# v1.3.4

## 新增

- 任务页支持「任务视图」，与网页端共用同一份规则（#4）；视图条件新增「分组」（需面板 v3.2.8）。
- 日志详情可一键跳到对应脚本（#5）。
- 脚本编辑页显示行号；查找改为常驻查找条，命中高亮（#6）。

## 修复

- 禁用的任务手动运行期间，菜单显示成「禁用」（需面板 v3.2.8）。
- 深色模式下日志背景是白色（#2）。
- 查找点「下一个」不跳转、定位跳偏（#6）。
- 编辑任务会丢掉订阅归属，下次拉取可能重复新建；按分组筛选会串到同名标签（#4）。
- 脚本加载失败时把错误文字当成脚本内容；打开脚本会先闪一下错误页。
- 脚本编辑器背景色设置不生效。

## 说明

- 与面板 v3.2.8 配套；装在老面板上也能用，需要新接口的功能会自动隐藏或降级。
