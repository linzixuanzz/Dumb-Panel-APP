# v1.3.5

## 修复

- 脚本管理页上传、新建、重命名之后，展开的目录不再折叠回顶层（#9）；连传多个脚本不用反复展开。
- 上传脚本、新建脚本、新建文件夹的默认目录改为你当前正在浏览的目录（#9）。
- 新建环境变量：变量名为空会就地提示；变量名不合规时显示面板给出的具体原因，不再出现「提示已创建、列表里却没有」（#8）。
- 启动卡在开屏页时不再只能清数据：超时后会说明卡在哪一步，并给出重试、返回登录、重新配置面板、清除本地会话四个出口（#7）。
