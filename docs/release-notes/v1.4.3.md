# v1.4.3

## 新功能

- 「更多」新增「配置文件」，可直接编辑面板的 config.sh，支持查找、未保存提醒（仅管理员，#22）。
- 任务卡左滑新增「日志」：运行中打开实时日志，否则打开最近一次日志。
- 依赖管理的镜像源新增「PyPI 官方」「npm 官方」快捷选项。

## 修复

- 窄屏手机上环境变量页右上角的「+」被挤出屏幕、点不了（#21）；任务页等页头同样处理。
- 订阅卡片底部的删除按钮跑到卡片外、点不了（#23）。
- 依赖管理看 Python 依赖时上方内容占太多位置（#23）：统计、运行时和筛选现在随列表滚走，勾选后「批量卸载」固定显示。
- 新建依赖时 `httpx[http2,socks]` 方括号里的逗号不再被当成分隔符。

## 注意

- 选「PyPI 官方」「npm 官方」需要面板 v3.3.9 及以上，老面板保存后会被换回默认加速源。
- 与面板 v3.3.9 同期发布；其余改动都不依赖新面板。
