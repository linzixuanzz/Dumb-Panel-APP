# v2.0.0

## 全新外观

- 改为 iOS 26 式的干净留白：浅灰底配白色大圆角卡片、系统蓝强调色、黑色胶囊主按钮；设置里可选浅色 / 深色 / 跟随系统。
- 底栏改为悬浮玻璃胶囊，5 个 Tab：任务（首页）/ 日志 / 概览 / 变量 / 设置。

## 新功能

- 常用任务：最多 5 张卡片左右滑动，按住 0.7 秒运行，防止误触。
- 任务详情改为弹层：成功率、平均耗时、P90、按天月历（红色表示当天有失败）、最近一次日志。
- 日志：四色筛选方块、执行趋势图、失败行直接显示错误行、左滑删除。
- 概览：近 30 天成功率、最慢的任务、最常失败、每天执行柱状图、服务器资源。
- 变量：敏感值默认遮蔽，开了应用锁时查看和复制要先验证；列表显示每个变量的更新时间（#27）。
- 任务列表新增 11 种快捷排序，与网页一致（#28）。
- 安卓：长按图标快捷方式（新建任务、搜索任务、运行常用任务）、桌面小组件、可选的「任务运行中」常驻通知；iOS 支持长按图标快捷方式。

## 注意

- 任务详情的统计和月历、概览的「最常失败」需要面板 v4.0.0 及以上，老面板上会自动隐藏。
- 「默认打开页面」原来的「主页」改为「任务」。
- 任务行不再显示「运行」按钮，改为在详情弹层或常用卡片里按住运行。
- iOS 最低版本提高到 14.0。
