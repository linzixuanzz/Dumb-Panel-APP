## v1.3.0 遗留的已知项

发版时明确记录、但没有做的事，避免下一轮重新调查一遍：

- **SSE 的 401 不会自动续期**：实时日志、日志详情流、依赖安装日志、订阅拉取流四条链路走 `package:http`，不经 dio 与拦截器。缓解因素是这些页面多从列表页进入、列表页的 REST 请求会先触发续期；但长时间挂着实时日志正是 token 过期的高发场景。
- **6 个 State 仍无 `error` 字段**：`NotificationListState` / `UserListState` / `DepListState` / `ScriptState` 等，断网时静默变空。
- **115 处裸 `showSnackBar(`**：绕过 `AppSnack`，其中 `env_list_page`(18) 与 `subscription_list_page`(12) 一次都没用过。
- **4 个 model 的 `toJson()` 是死代码**：真实请求体是页面内联字面量，每个实体两份字段清单。`Subscription` 那份已删。
- **6 处点击区低于 48dp**：`main_scaffold` 导航项 36dp、`app_buttons` 32dp、`subscription` 的 `_SmallIconBtn` 30dp 等，都是本轮之前就存在的。修它们要还回密度。
- **仪表盘「在线」圆点不绑定任何状态**：颜色语义已改对（success 绿），但面板不可达时它照样常亮。要真修得接 `dashboardProvider` 的 error / 心跳。
- **`FormData` 请求重发不可靠**：脚本上传、备份上传的流已被消费过，401 续期后重发大概率失败。改动前后都存在。
