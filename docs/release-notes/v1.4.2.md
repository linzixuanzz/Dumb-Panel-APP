# v1.4.2

## 新功能

- 点定时任务进入详情页，可查看命令、定时规则、上次和下次运行、运行时长、最新日志与日志历史；点脚本直接打开编辑（#20）。
- 自动弹出的更新提示新增「忽略此版本」和「不再自动提醒」，可在「设置 → 自动提醒更新」重新打开（#19）。

## 修复

- 每次回到首页都弹出更新提示（#19）：现在每次启动最多提示一次。
- 打开 3000 行以上的脚本时编辑卡顿（#18）。
- 环境变量搜索后点清空，列表有时停在旧的搜索结果（#18）。

## 注意

- 点任务卡片改为进入详情页，查看日志请点详情页里的「最新日志」。
- 与面板 v3.3.8 同期发布；以上改动都不依赖新面板。
