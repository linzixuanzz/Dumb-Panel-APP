# v1.3.1

## 版本概览

这一版的主题和面板 `v3.0.2` 一样：**消灭静默失败**——APP 在出问题时不再假装一切正常。

过去断网或面板不可达时，六个列表页会静默变成「暂无数据」，看起来像是真的没有内容；仪表盘的「在线」绿点更是无论如何都亮着。现在它们会如实告诉你「拿不到数据」。

同时把够不着的按钮统一修了一遍——底部导航、返回按钮、各页面的操作图标此前都小于可用尺寸。

## 修复

- **断网时不再假装「暂无数据」**：通知渠道、用户、依赖、脚本、订阅五个列表页在请求失败时会显示错误原因和「重试」按钮，而不是一片空白。

  > 其中订阅页属于「改了一半」——错误信息其实一直有记录，但页面从来没读过它，所以表现和完全没做一样。

- **仪表盘的「在线」圆点终于绑定真实状态**：此前它是写死的绿色，面板挂掉、接口报错时照样常亮。

  > 它的准确语义是「最近一次拉取成功与否」，**不是心跳**：面板刚挂、而下一次拉取还没发生时它仍然是绿的。这一条只负责消掉「明明加载失败了还亮绿灯」这种主动骗人的情形。

- **上传脚本、上传备份时如果登录态刚好过期，不再失败**：登录续期后重发请求会带上完整的文件内容。

  > 此前续期是成功的、重发却必然失败——因为重发复用的是同一个已经被消费过的文件流，而用户只看到一句「上传失败」，完全看不出是登录态的问题。

- **Open API 应用现在能勾上「通知渠道」和「系统备份」两个权限**：面板一共有 8 个权限范围，APP 的勾选列表只列了 6 个。表现不是报错，而是这两个权限**永远勾不上**，建出来的应用调对应接口一律 403。

- **搜索脚本时不再把加载失败的提示冲掉**：脚本树加载失败后，一敲搜索框错误提示就消失、退回「暂无脚本」，看起来像是搜不到，实际上是根本没加载成功。依赖页也有同类问题。

## 优化

- **够不着的按钮统一修了一遍**，命中区都抬到了 44dp，**视觉尺寸和排版一点没变**：

  | 位置 | 原命中区 |
  |---|---|
  | 全部 11 个页面的返回按钮 | 20dp，且图标笔画之间的透明像素还不响应点击 |
  | 底部导航栏的五个 tab | 36dp——全 App 点得最频繁的地方 |
  | 各页面右上角的圆形「新建」按钮（7 处） | 32dp |
  | 任务分组的「更多」菜单 | 18dp |
  | 订阅卡片上的编辑 / 日志 / 拉取 / 删除（4 个调用点） | 30dp |
  | 脚本页刷新、依赖页日志、设置页显示密码、任务表单加标签等 | 30–36dp |
  | 日志页、脚本页的删除 / 更多按钮 | 40dp |

  依赖列表的勾选框只有 24dp，但那张卡的高度已经没有余量，所以改成了**整卡可点**（任务页和环境变量页本来就是这样）。

- **全部 111 处提示条统一走 `AppSnack`**：此前散落在 14 个文件里的裸提示条各写各的，版式和配色都不统一。顺带按语义分了色——校验没过、平台不支持这类不再一律报红。

- **删掉 4 个 model 里没人调用的 `toJson()`**：真实请求体是页面里的内联字面量，同一个实体存在两份字段清单，改一处漏一处。

## 说明

- 本版与面板 `v3.0.2` 配套，但**两边互不依赖**：APP 在旧面板上会自动降级，面板升级后不装新 APP 也能正常用。
- 「通知渠道」「系统备份」这两个权限范围在面板 `v3.0.0` 之后就存在，不需要升级面板也能勾选。
