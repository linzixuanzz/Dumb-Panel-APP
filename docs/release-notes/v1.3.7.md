# v1.3.7

## 新功能

- 多服务器切换不再需要退出登录（#13）：每台面板的登录状态分别保存，切回已经登录过的面板直接进首页，开了两步验证也不用再验一次。
- 新增「关于」页（#12）：作者头像与主页、面板与 App 两个项目地址、两个问题反馈入口，点一下直接打开。

## 修复

- 内置安装失败（#11）：安装改用系统的 PackageInstaller，不再依赖调起第三方安装器，国产系统和开了纯净模式的设备也能装上。
- 安装失败时提示里写的是「下载失败」，实际下载已经完成，容易被带偏（#11）。
- 安装失败后没有任何出路：现在会给出中文原因，并按情况提供「重试安装」「重新下载」「去开启权限」，还能一键复制错误详情。
- 没开「安装未知应用」权限时直接失败：现在会先带你去设置页。
- 下载中途被杀掉进程留下的半截安装包会被当成完整包复用。

## 注意

- 升级后原有的登录状态会自动迁移，不会被踢下线。
- 改了某台面板的地址等于换了一台，该面板需要重新登录一次。
- 多台面板的登录凭据都保存在设备上，建议同时开启 App 锁。
- 与面板 v3.3.2 同期发布；装在老面板上也能用。
