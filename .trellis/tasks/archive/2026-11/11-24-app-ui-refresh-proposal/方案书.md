## 2. 设计方向

### 2.1 怎么走到这一版的

| 版本 | 思路 | 结果 |
|---|---|---|
| ① 跟随网页 | 照搬网页 v4.0 的 6 套主题与极光玻璃 | ❌ 你说 APP 不必和网页一样 |
| ② 口袋版 | Material 3 色调体系 + 会变表情的呆呆 | ❌ 你说有「落后的味道」 |
| ③ 风格样稿 | 液态玻璃 / 点阵极客 / 暗黑霓虹 / 3D 粘土各出一张主页 | 你给了参考截图 |
| **④ 本方案** | **按参考截图的 iOS 26 干净留白重做** | 待拍板 |

### 2.2 设计原则

1. **留白和字重说话**：大标题 34pt 加粗，卡片之间留足 16pt，不靠边框和阴影分层。
2. **颜色只给数据**：成功、失败、运行中、耗时这些状态才上色，界面本身是黑白灰。
3. **主操作永远是黑色胶囊**（深色模式下变成白色胶囊），一屏最多一个。
4. **玻璃只用在悬浮层**：底栏、右上角圆形按钮、锁屏卡片。内容卡片是实心白，低端机也不卡。
5. **危险操作要「按住」**：运行任务需要按住 0.7 秒，进度条走满才触发，同时轻振一下。

### 2.3 设计令牌

| 令牌 | 浅色 | 深色 | 说明 |
|---|---|---|---|
| 底色 | `#F2F2F7` | `#000000` | 与 iOS 分组背景一致 |
| 卡片 | `#FFFFFF` | `#1C1C1E` | 无边框、无阴影 |
| 次级填充 | `rgba(118,118,128,.12)` | `rgba(118,118,128,.24)` | 分段控件、搜索框 |
| 正文 / 次要 / 弱化 | `#000` / `#8A8A8E` / `#B0B0B5` | `#FFF` / `#8D8D93` / `#5F5F65` | |
| 分隔线 | `rgba(60,60,67,.13)` | `rgba(84,84,88,.55)` | 左侧缩进到图标之后 |
| 强调 | 蓝 `#007AFF`、绿 `#34C759`、红 `#FF3B30`、橙 `#FF9500`、紫 `#AF52DE` | 对应的深色版 | 只用在状态与数据 |
| 主按钮 | 黑底白字 | 白底黑字 | |
| 圆角 | 卡片 30、小卡 28、图标方块 15、胶囊 999 | 同左 | 统一收进 `AppRadius` |
| 字号 | 大标题 34、区块标题 22、卡片标题 21、正文 16.5、说明 13.5 | 同左 | 数字一律等宽 |

现有的 `core/theme/design_tokens.dart`（`AppRadius`、`AppSpacing`、`AppSurfaces`）结构保留，只换数值、补令牌。

### 2.4 组件清单

| 组件 | 用在哪 | 要点 |
|---|---|---|
| 大标题头 | 每个 Tab 顶部 | 左边大标题，右边 1~2 个圆形玻璃按钮 |
| **缺口卡片** | 任务页「常用任务」 | 右下角挖出带反向圆角的缺口，黑色胶囊嵌在里面；用 `CustomClipper` 画路径 |
| 分组列表 | 所有任务、变量、设置 | 白色大圆角容器，行之间是缩进分隔线 |
| 彩色图标方块 | 列表行、日志筛选、小卡片 | 浅色底配同色图标（绿 / 红 / 蓝 / 紫 / 橙） |
| 分段控件 | 概览、图表切换 | 灰色胶囊，选中块是白色，用弹簧动画滑过去 |
| 悬浮玻璃底栏 | 全局 | 5 个实心图标加文字，选中项后面一块灰色药丸，切换时药丸弹簧滑动 |
| 卡片式弹层 | 任务详情 | 背后的页面缩小变暗（iOS 卡片式模态） |
| 细线图表 | 日志趋势、每月执行 | 沿用 `fl_chart`，网格线极细，配一行灰色说明 |
| 渐变总览卡 | 概览 | 淡紫渐变，大数字成功率 |
| 星空个人卡 | 设置 | 黑到蓝紫的渐变加星点，呆呆头像 |

### 2.5 动效

| 动效 | 做法 | 减少动态效果时 |
|---|---|---|
| 底栏药丸滑动 | 弹簧曲线位移 | 直接跳 |
| 切 Tab | 淡出 0.12s，新页淡入并从 0.97 放大到 1 | 直接切 |
| 详情弹层 | 从底部弹起，背景缩到 0.93 并变暗 | 只淡入 |
| 按住运行 | 胶囊内进度条 0.7s 走满，触发时轻振，顶部弹出提示 | 保留（这是功能） |
| 切明暗 | 从点击处圆形扩散 | 直接切 |
| 列表入场 | 逐行上浮，每行错开 55ms | 无 |
| 运行中图标 | 圆弧转圈 | 静止 |

一律尊重系统设置：安卓「移除动画」、iOS「减弱动态效果」。

## 3. 页面结构

底栏从「主页 / 任务 / 日志 / 变量 / 更多」改成「**任务 / 日志 / 概览 / 变量 / 设置**」。

| 新 Tab | 内容 | 由谁演变而来 |
|---|---|---|
| **任务**（首页） | 「Hi, admin!」问候；常用任务卡片（最多 5 张，左右滑，缺口里嵌「按住运行」）；所有任务分组列表（下次运行倒计时、可排序） | 旧「任务」+ 旧「主页」的快捷入口 |
| **日志** | 月份大标题；一句话总结今天；成功 / 失败 / 运行中 / 已终止四个彩色方块筛选；执行趋势细线图（**今天按已过时长折算，不再画成断崖**）；失败行直接展开错误行；左滑删除 | 旧「日志」 |
| **概览** | 呆呆头像问候；渐变总览卡（本月成功率、失败次数、定时 / 手动占比）；最慢的任务、最常失败；每月执行柱状图；服务器资源 | 旧「主页」的统计部分 |
| **变量** | 搜索；按分组排列；敏感值默认遮蔽，查看前验证指纹 | 旧「变量」 |
| **设置** | 星空个人卡；面板（服务器管理、应用锁）；外观（浅色 / 深色预览卡 + 跟随系统）；小组件与快捷方式；管理（脚本、订阅、依赖、通知渠道、用户、安全、Open API） | 旧「更多」 |
| 任务详情（弹层） | 成功率 / 平均耗时 / P90；月历（每天一个圆点，红色表示有失败）；最近一次日志；「按住立即运行」 | 旧任务详情页 |

## 5. 技术要点（Flutter）

- **主题**：重写 `core/theme/app_theme.dart`、扩充 `design_tokens.dart`。`ThemeMode` 改成读本机设置（已有 `shared_preferences`）。
- **少用 Material 默认外观**：底栏、卡片、分段控件、胶囊按钮都自绘，避免一眼「安卓默认样式」。两个平台观感一致。
- **玻璃**：只在底栏和圆形按钮用 `BackdropFilter`。低端机（或开了省电模式）降级为 92% 不透明的纯色。
- **缺口卡片**：`CustomClipper<Path>` 画「圆角矩形减去右下角圆角缺口，外加两个反向圆角」，按钮放在缺口里。
- **卡片式弹层**：Flutter 新版自带 `CupertinoSheetRoute`（背景缩放的 iOS 弹层），APP 用的 3.41.9 应该可用，**需要实测**。
- **数字**：`FontFeature.tabularFigures()` 等宽，倒计时跳动时不抖。
- **图表**：继续用 `fl_chart`，只改配色和网格。
- **新依赖**：A8 的通知插件、A9 的 `home_widget`、A10 的 `quick_actions`。**需要你确认要不要引入**。
- **验收**：`flutter analyze` 维持 7 条 info 的基线，`flutter test` 全过；新增组件补 widget test（注意记忆里记录的两个异步测试陷阱）。

## 7. 风险

| 风险 | 对策 |
|---|---|
| 安卓用户觉得「太像 iPhone」 | 底栏、卡片自绘但保留安卓返回手势与系统字体；先发测试版收集反馈 |
| 玻璃模糊在低端机掉帧 | 只用在两处悬浮层，并自动降级 |
| 改动面大，回归风险高 | 阶段一不碰业务逻辑，只换外观与布局；按页面逐个替换 |
| iOS 实时活动、小组件要写原生代码 | 放到阶段三，单独评估 |

## 附录：效果演示怎么玩

- 点底栏切页，看灰色药丸弹簧滑动
