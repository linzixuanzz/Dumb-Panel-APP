# APP v2.0 视觉焕新与系统集成

## 目标

按 `方案书.md`（iOS 26 干净留白方向）把 APP 从 v1.4.6 改版为 **v2.0**：新设计令牌与明暗设置、5 个 Tab 重排、悬浮玻璃底栏、常用任务卡片与按住运行、任务详情弹层、概览页、日志筛选、变量指纹查看，以及安卓系统集成（快捷方式、桌面小组件、运行中常驻通知）。效果参照 `APP效果演示.html` 与 `images/新-*.png`。

### 按推荐直接定下的细节（评审时可推翻）

| 项 | 决定 |
|---|---|
| iOS 系统集成范围 | iOS 只做快捷方式（`quick_actions` 无需扩展）。桌面小组件与锁屏实时活动要 Xcode 扩展 target 与 App Group 签名权限，未签名 IPA 自签安装带不上，本期不做 |
| 安卓常驻通知 | 只在 APP 进程存活时显示「N 个任务运行中」，不做前台服务（不常驻后台、不额外耗电）；安卓 13+ 首次开启时申请通知权限 |
| 桌面小组件 | 今日成功率、下一个任务、最近失败的任务（点按打开 APP 对应页面）；数据在 APP 打开 / 刷新时写入，小组件只读快照，不在后台联网 |
| 默认打开页面（#24） | 选项改为 任务 / 日志 / 概览 / 变量；旧值 `dashboard`（主页）映射为「任务」（新首页）；`/dashboard`、`/more` 路由保留并重定向到 `/overview`、`/settings` |
| 依赖面板 v4.0 的功能 | 按 `panel-contract.md`「形状探测」：新接口 404 / 不认识的形状时隐藏或降级，不看版本号 |
| 明暗设置 | 浅色 / 深色 / 跟随系统，默认跟随系统，存本机（应用级，所有面板共用） |
| 减少动态效果 | 跟随系统（`MediaQuery.disableAnimations`），按住运行的进度条保留 |
| 次级页面（脚本、订阅、依赖、通知、用户、安全、Open API、系统设置、备份等） | 不重做布局，只吃新令牌、去掉写死颜色、统一大标题头 / 分组列表 / 胶囊按钮 |

## 验收标准

1. `flutter analyze` 不超过基线 7 条 info；`flutter test` 全过（含新增 widget test）；`flutter build apk` 成功（含原生代码编译）。
2. 令牌：浅 / 深两套按方案书 §2.3；主按钮黑底白字（深色白底黑字）；正文与次要文字对比度 ≥ 4.5:1（弱化文字仅用于非关键信息）。
3. 5 个 Tab 与悬浮玻璃底栏，选中药丸弹簧滑动；切 Tab 淡入；系统「移除动画」时无动画。
4. 任务页：问候、常用任务卡片（最多 5 张、左右滑、本机存储、可在任务行上加 / 移出常用）、缺口里嵌「按住运行」（0.7s、轻振、松手取消）；所有任务列表保留既有筛选 / 视图 / 分组 / 快捷排序 / 拖拽排序 / 批量能力。
5. 任务详情弹层：成功率 / 平均耗时 / P90、月历（每天圆点，红 = 当天有失败）、最近一次日志、按住运行；老面板（health 404）只显示最近日志，不报错。
6. 日志：一句话总结、四色筛选方块、趋势细线图（今天按已过时长折算，不画断崖）、失败行直接显示错误行、左滑删除。
7. 概览：渐变总览卡、最慢任务、最常失败（需 attention 接口，老面板隐藏）、每月执行柱状图、服务器资源。
8. 变量：敏感值默认遮蔽，查看 / 复制前指纹（或设备密码）验证；设备不支持生物识别时按现有应用锁策略降级。
9. 设置：星空个人卡、面板（服务器管理、应用锁）、外观（浅 / 深预览卡 + 跟随系统）、小组件与快捷方式说明、管理入口；「默认打开页面」新选项与旧值映射正确。
10. 安卓：长按图标出现「新建任务 / 搜索任务 / 运行常用任务」；桌面小组件可添加并显示快照；有任务运行时出现常驻通知、全部结束后消失；iOS 快捷方式可用。
11. 兼容：连 v3.4.x 面板全部页面可用，v4.0 专属卡片隐藏；旧版默认打开页面设置升级后不报错。
12. 版本 2.0.0：`pubspec.yaml`、README、发布说明同步。

## 不在本次范围
